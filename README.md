# GxG (Goose Goose)

A game about geese. Eldritch geese, to be more precise.

## Story premise/plot

> "In the beginning, before the dawn of time, when Chaos and Entropy were the only things in existence... there was Father Goose. When God created the angels, Father Goose created the Devil and temptation. When God created the universe, Father Goose chased him. Then God created the Multiverse to flee from Father Goose. Father Goose was displeased at The LORD's cowardice."
